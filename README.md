# Homebrew tap

Casks for my macOS applications.

## Install

```sh
brew install --cask nicglazkov/tap/overhang
```

Or tap first, then install by short name:

```sh
brew tap nicglazkov/tap
brew install --cask overhang
```

## Casks

| Cask | Description |
|---|---|
| [overhang](https://github.com/nicglazkov/overhang) | Recovers the menu bar icons macOS hides behind the notch |
